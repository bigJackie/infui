# 主题工作区（theme）

设计令牌与组件样式。

## 目录职责

- 语义变量：`src/variables/`
- 组件样式：`src/components/`
- 样式主入口：`src/index.scss`

## 构建

```bash
cd /Users/wangxinrui/WebstormProjects/infui
pnpm -C packages/theme run build
```

## 开发监听

```bash
cd /Users/wangxinrui/WebstormProjects/infui
pnpm -C packages/theme run dev
```
