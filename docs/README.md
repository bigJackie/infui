# 文档工作区（docs）

VitePress 文档工作区。

## 目录职责

- 组件文档页面：`pages/`
- 交互示例：`examples/`
- 站点配置：`.vitepress/`

## 本地运行

```bash
cd /Users/wangxinrui/WebstormProjects/infui
pnpm -C docs run dev
```

## 构建与预览

```bash
cd /Users/wangxinrui/WebstormProjects/infui
pnpm -C docs run build
pnpm -C docs run preview
```
